# 📈 ใบงานที่ 9: การวิเคราะห์และแสดงผลข้อมูลย้อนหลังด้วย Grafana

คู่มือการทดลองเชื่อมต่อ **Grafana** เข้ากับฐานข้อมูล **InfluxDB** เพื่อสร้างแดชบอร์ดวิเคราะห์สถิติข้อมูลย้อนหลัง (Historical Analytics Dashboard) ด้วยภาษา **Flux Query**

---

## 🎯 วัตถุประสงค์ (Objectives)

1. เข้าใจสถาปัตยกรรมของ **Grafana** ในการดึงข้อมูลจากหลายแหล่ง (Data Sources) มาสร้าง Data Visualization
2. สามารถเขียนคำสั่ง **Flux Query Language** เพื่อกรอง (Filter), จัดกลุ่ม (Group) และรวมสถิติ (Aggregate) ข้อมูลเซ็นเซอร์
3. เข้าใจเทคนิคการลดรูปข้อมูล (**Downsampling**) ด้วยฟังก์ชัน `aggregateWindow()` และการใช้ตัวแปร `v.windowPeriod` เพื่อให้กราฟเรนเดอร์ได้รวดเร็วตามช่วงเวลาที่ซูม
4. สามารถสร้างพาเนลแสดงผลหลากหลายรูปแบบ เช่น **Time Series Chart**, **Stat Panel**, **Gauge**, และการตั้งค่าเกณฑ์สี (Thresholds)

## ✍️ เฉลยคำตอบในใบงาน (Worksheet Answers)

### 1. โค้ดคำสั่ง Flux Query (ดึงค่าเฉลี่ยความชื้นย้อนหลัง 24 ชั่วโมง)
```flux
from(bucket: "iot_bucket")
  |> range(start: -24h)
  |> filter(fn: (r) => r["_measurement"] == "climate_sensor")
  |> filter(fn: (r) => r["_field"] == "humidity")
  |> aggregateWindow(every: v.windowPeriod, fn: mean, createEmpty: false)
  |> yield(name: "mean_humidity")
```

### 2. คำถามสรุปผลการทดลอง (Review Questions)

**คำถามที่ 1: ข้อดีของการแยกแดชบอร์ดฝั่ง Node-RED (ควบคุมหน้างานเรียลไทม์) และ Grafana (วิเคราะห์สถิติย้อนหลัง) ออกจากกันมีประโยชน์อย่างไร?**
> **แนวคำตอบ:** Node-RED Dashboard เน้นการสั่งการและควบคุมสวิตช์หน้างานแบบทันที (Low Latency Control) เหมาะสำหรับผู้ปฏิบัติงานประจำวัน ส่วน Grafana เน้นการวิเคราะห์ข้อมูลปริมาณมหาศาลย้อนหลังหลายเดือน/หลายปี (Long-term Trend Analysis) มีระบบความปลอดภัยสูง รองรับการซูมเปรียบเทียบข้อมูลย้อนหลัง ทำรายงานส่งผู้บริหาร และมีระบบ Alerting แจ้งเตือนเมื่อข้อมูลผิดปกติ การแยกกันทำให้ระบบควบคุมหน้างานไม่สะดุดแม้มีการ Query ข้อมูลหนักใน Grafana

**คำถามที่ 2: ฟังก์ชัน `aggregateWindow()` ใน Flux Query ทำหน้าที่อะไร และ `v.windowPeriod` มีความสำคัญอย่างไร?**
> **แนวคำตอบ:** `aggregateWindow()` ทำหน้าที่แบ่งช่วงเวลาออกเป็นหน้าต่างย่อยๆ (Time Windows) แล้วคำนวณหาค่าสถิติตัวแทน (เช่น ค่าเฉลี่ย `mean` หรือค่ายอด `max`) เพื่อลดจำนวนจุดข้อมูลที่ต้องวาดลงบนจอ (Downsampling) ส่วนตัวแปร `v.windowPeriod` คือตัวแปรอัตโนมัติของ Grafana ที่จะปรับขนาดหน้าต่างเวลาให้เหมาะสมกับความกว้างหน้าจอและช่วงเวลาที่ผู้ใช้กำลังเลือกดู (เช่น ถ้าดู 1 วันจะเฉลี่ยทุก 5 นาที แต่ถ้าดู 1 ปีจะเฉลี่ยทุก 1 วัน) ป้องกันบราวเซอร์ค้างจากการโหลดข้อมูลหลายล้านจุดพร้อมกัน
