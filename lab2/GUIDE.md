# 📟 ใบงานที่ 2: การแสดงผลผ่านจอ OLED SSD1306 (I2C)

คู่มือการทดลองเชื่อมต่อจอแสดงผล **OLED 0.96 นิ้ว SSD1306 (ความละเอียด 128x64 พิกเซล)** ผ่านการสื่อสารบัส **I2C** พร้อมนำค่าจากเซ็นเซอร์ DHT11, Potentiometer และสถานะสวิตช์ปุ่มกดมาจัดวางแสดงผลแบบมัลติข้อมูล

---

## 🎯 วัตถุประสงค์ (Objectives)

1. เข้าใจโปรโตคอลการสื่อสารแบบอนุกรม **I2C (Inter-Integrated Circuit)** ซึ่งใช้สายสัญญาณเพียง 2 เส้น ได้แก่ **SDA (Data)** และ **SCL (Clock)**
2. สามารถเริ่มต้นใช้งานไลบรารี `Adafruit_GFX` และ `Adafruit_SSD1306` เพื่อควบคุมจอแสดงผลกราฟิก
3. เข้าใจบทบาทของ **Frame Buffer** ในหน่วยความจำ RAM และคำสั่ง `display.display()` ในการส่งข้อมูลขึ้นหน้าจอ
4. สามารถออกแบบ UI และจัดวางตำแหน่งข้อความ กราฟิก และค่าตัวแปรจากเซ็นเซอร์บนหน้าจอขนาด 128x64 พิกเซลได้อย่างเป็นระเบียบ

---

## 🔌 การต่อวงจรและพินฮาร์ดแวร์ (Hardware Pinouts)

| สัญญาณจอ OLED | บอร์ด ESP32 (IPST-WiFi) | บอร์ด ESP8266 (AX-WiFi) | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| **SDA (Data)** | `GPIO 21` (I2C Default) | `GPIO 4` (`D2`) | สายสัญญาณข้อมูล |
| **SCL (Clock)** | `GPIO 22` (I2C Default) | `GPIO 5` (`D1`) | สายสัญญาณนาฬิกา |
| **VCC / GND** | `3.3V` / `GND` | `3.3V` / `GND` | ไฟเลี้ยงโมดูลจอ |

### 2. คำถามสรุปผลการทดลอง (Review Questions)

**คำถามที่ 1: สัญญาณ SDA และ SCL ในบัส I2C ทำหน้าที่อะไร และมีข้อดีอย่างไรเมื่อเทียบกับการต่อจอแบบขนาน (Parallel)?**
> **แนวคำตอบ:** `SDA (Serial Data)` ทำหน้าที่รับส่งข้อมูลไบนารีระหว่าง Master และ Slave ส่วน `SCL (Serial Clock)` ทำหน้าที่สร้างสัญญาณนาฬิกาเพื่อกำหนดจังหวะการรับส่งข้อมูล ข้อดีคือใช้สายสัญญาณเพียง 2 เส้นในการเชื่อมต่ออุปกรณ์ได้หลายตัวพร้อมกันบนบัสเดียวกัน (ผ่านการระบุ Address เช่น `0x3C`) ประหยัดขา GPIO มากกว่าแบบ Parallel ที่ต้องใช้สาย 8–16 เส้น

**คำถามที่ 2: เหตุใดเมื่อเราใช้คำสั่งวาดภาพหรือเขียนข้อความลงใน `display.print()` แล้ว หน้าจอยังไม่แสดงผลจนกว่าจะเรียกใช้ `display.display()`?**
> **แนวคำตอบ:** เนื่องจากไลบรารีใช้โครงสร้างแบบ **Frame Buffer (บัฟเฟอร์ในแรม)** ขนาด 1024 ไบต์บน RAM ของไมโครคอนโทรลเลอร์ คำสั่ง `print` หรือวาดเส้นจะแก้ไขข้อมูลใน Frame Buffer ก่อน เพื่อให้การวาดภาพเร็วและไม่มีอาการจอกะพริบ เมื่อเตรียมข้อมูลครบจึงสั่ง `display.display()` เพื่อส่งข้อมูลทั้งหมดก้อนเดียวผ่านบัส I2C ไปยังไดรเวอร์ SSD1306
