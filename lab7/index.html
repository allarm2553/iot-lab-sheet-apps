ขั้นตอนการทดลอง

  1. เปิดหน้าแก้ไข Node-RED ผ่านเว็บเบราว์เซอร์ที่ URL: http://localhost:1880
  2. ลากโหนด mqtt in มาวางในพื้นที่ทำงาน ดับเบิลคลิกเพื่อตั้งค่าเซิร์ฟเวอร์ Broker ดังนี้:
    • Server: broker.emqx.io
    • Port: 1883
    • Topic: esp32-climate-node/sensor/room_temperature/state
  3. ลากโหนด json มาต่อท้ายโหนด MQTT เพื่อแปลงข้อมูลสตริงเป็น Object ตัวเลขในภาษา JavaScript
  4. ลากโหนด gauge จากหมวดหมู่ Dashboard มาวาง ตั้งเกณฑ์ช่วงอุณหภูมิ 0 ถึง 50 และตั้งชื่อโหนดว่า "Temperature Gauge" จากนั้นเชื่อมสายต่อจากโหนด JSON
  5. การสร้างปุ่มควบคุมส่งกลับ (Control Row):
    • ลากโหนด ui_switch มาวาง กำหนดค่าเมื่อเปิด (On Payload) เป็นสตริง ON และเมื่อปิด (Off Payload) เป็นสตริง OFF
    • ลากโหนด mqtt out มาวาง ดับเบิลคลิกเชื่อมโยงไปยัง Server ตัวเดิม และตั้งค่า Topic สำหรับส่งคำสั่งควบคุมพัดลมระบายความร้อน: esp32-climate-node/switch/cooling_fan_relay/command

โจทย์ท้าทายการทดลอง (Challenge)

ทฤษฎีที่เกี่ยวข้อง: การเชื่อมโยงข้อมูลและการสร้างแดชบอร์ดด้วย Node-RED

1.1 สถาปัตยกรรม Flow-Based Programming

Node-RED เป็นแพลตฟอร์ม Visual Programming แบบ Flow-based ที่พัฒนาบน Node.js เหมาะสำหรับเชื่อมต่อฮาร์ดแวร์, API, และบริการออนไลน์ โดยข้อความทั้งหมดจะถูกส่งต่อระหว่างโหนดในรูปของ JavaScript Object ชื่อว่า msg

2.1 โหนด json และ Function Node

โหนด json: แปลงข้อความสตริง JSON ที่รับมาจาก mqtt in ให้กลายเป็น JavaScript Object ทำให้สามารถอ้างอิงฟิลด์ข้อมูลย่อยได้ทันที เช่น msg.payload.temperature

Function Node: เขียนโค้ด JavaScript ประมวลผลเงื่อนไข เช่น:

if (msg.payload.humidity < 20) {
  msg.payload = "Alert: Dry Climate!";
  return msg;
}
return null; // ไม่ส่งต่อข้อความถ้าไม่เข้าเงื่อนไข

3.1 การสร้าง UI ด้วย node-red-dashboard

ชุดโหนด UI เช่น ui_gauge (เกจวัดค่า), ui_chart (กราฟเส้นแสดงแนวโน้ม), และ ui_switch (สวิตช์ควบคุม) ช่วยให้สร้างหน้าเว็บแดชบอร์ดควบคุมระบบได้ในเวลาไม่กี่นาทีผ่าน URL http://localhost:1880/ui

4.1 รูปแบบข้อความทดสอบในโหนด Inject และ Debug Message Box

เมื่อทดสอบส่งข้อความจำลองจากโหนด Inject หรือดูข้อมูลในหน้าต่าง Debug Sidebar ข้อความจะต้องมีโครงสร้างตามตารางนี้:

โหนด / เครื่องมือ ข้อความ Payload ที่ต้องพิมพ์ใน Message Box ผลลัพธ์ใน Flow และ Dashboard
Inject Node (JSON) {"temp": 33.5, "humidity": 58.0} จำลองข้อมูลเซ็นเซอร์ส่งเข้าโหนด ui_gauge และ ui_chart
Inject Node (Boolean) true หรือ false สั่งเปิด/ปิดพัดลมจำลองผ่าน MQTT topic .../cmd/fan
Function Node (Payload Mapping) msg.payload = { "fan": msg.payload ? 1 : 0 }; แปลง Boolean จาก UI Switch ให้เป็นตัวเลขก่อนส่งเข้า MQTT
