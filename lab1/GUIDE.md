# 🌡️ ใบงานที่ 1: การอ่านค่าเซ็นเซอร์และการควบคุมเอาต์พุต (GPIO, ADC & Relays)

คู่มือการทดลองควบคุมไมโครคอนโทรลเลอร์ ESP32 / ESP8266 ในการอ่านค่าเซ็นเซอร์อุณหภูมิและความชื้น (DHT11), ตัวต้านทานปรับค่าได้ (Potentiometer / ADC) และการสั่งงานรีเลย์ควบคุมพัดลมและหัวพ่นหมอก

---

## 🎯 วัตถุประสงค์ (Objectives)

1. สามารถกำหนดโหมดของขา GPIO เป็น `INPUT` และ `OUTPUT` ได้อย่างถูกต้อง
2. สามารถอ่านค่าความต่างศักย์ไฟฟ้าแบบแอนะล็อกผ่านตัวแปลงสัญญาณ **ADC (Analog-to-Digital Converter)** และแปลงเป็นเปอร์เซ็นต์ (0–100%)
3. สามารถติดต่อสื่อสารและอ่านข้อมูลอุณหภูมิและความชื้นสัมพัทธ์จากเซ็นเซอร์ **DHT11**
4. เข้าใจหลักการควบคุมแบบ **Hysteresis (ส่วนต่างของจุดตัด)** เพื่อป้องกันปัญหารีเลย์เปิด-ปิดถี่เกินไป (Relay Clicking / Chatter)

## ✍️ เฉลยคำตอบในใบงาน (Worksheet Answers)

### 1. โค้ดเติมช่องว่าง (Code Blanks)
* ตั้งค่าพินรีเลย์เป็นเอาต์พุต:
  ```cpp
  pinMode(FAN_RELAY_PIN, OUTPUT);
  pinMode(MIST_RELAY_PIN, OUTPUT);
  ```
* คำนวณเปอร์เซ็นต์ ADC:
  ```cpp
  analogPercent = (rawAnalog / 4095.0) * 100.0; // สำหรับ ESP32 (1023.0 สำหรับ ESP8266)
  ```
* การเปิด-ปิดรีเลย์ตามสถานะ:
  ```cpp
  digitalWrite(FAN_RELAY_PIN, HIGH);
  digitalWrite(FAN_RELAY_PIN, LOW);
  ```

### 2. คำถามสรุปผลการทดลอง (Review Questions)

**คำถามที่ 1: ความละเอียดของ ADC บน ESP32 และ ESP8266 แตกต่างกันอย่างไร และแปลงค่าแรงดันเป็นตัวเลขได้ช่วงใด?**
> **แนวคำตอบ:** ESP32 มีความละเอียด ADC 12-bit (ให้ค่าจำนวนเต็ม 0 ถึง 4095 ที่ช่วงแรงดัน 0–3.3V) ส่วน ESP8266 มีความละเอียด ADC 10-bit (ให้ค่าจำนวนเต็ม 0 ถึง 1023 ที่ช่วงแรงดัน 0–1.0V หรือ 0–3.3V บนบอร์ดพัฒนา)

**คำถามที่ 2: เหตุใดจึงต้องใช้วงจรรีเลย์ (Relay Module) หรือทรานซิสเตอร์ในการขับพัดลมและปั๊มน้ำ แทนการต่อตรงกับขา GPIO ของไมโครคอนโทรลเลอร์?**
> **แนวคำตอบ:** ขา GPIO ของไมโครคอนโทรลเลอร์จ่ายกระแสได้สูงสุดเพียงประมาณ 12–20mA ที่แรงดัน 3.3V ซึ่งไม่เพียงพอต่อการขับโหลดมอเตอร์พัดลมหรือปั๊มน้ำที่ต้องการกระแสสูง (100mA–1A+) และแรงดัน 5V/12V/220V การใช้โมดูลรีเลย์ช่วยแยกวงจรไฟฟ้าแรงดันต่ำออกจากโหลดกำลังสูง ป้องกันชิปไมโครคอนโทรลเลอร์เสียหายจากกระแสไฟเกินและแรงดันไฟเหนี่ยวนำย้อนกลับ (Back EMF)
