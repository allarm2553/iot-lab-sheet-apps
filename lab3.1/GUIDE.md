# 📶 ใบงานที่ 3.1: การตรวจหา WiFi และการเชื่อมต่อ Station Mode (WiFi Scan & Connect)

คู่มือการทดลองสั่งงานโมดูล Wi-Fi ของ ESP32 และ ESP8266 ในการสแกนหาเครือข่ายไร้สาย (WiFi Scanner) และการเชื่อมต่อเข้าสู่อินเทอร์เน็ตในโหมด **Station (STA)**

---

## 🎯 วัตถุประสงค์ (Objectives)

1. เข้าใจโหมดการทำงานของ Wi-Fi บนไมโครคอนโทรลเลอร์ ได้แก่ **Station Mode (WIFI_STA)**, **Access Point Mode (WIFI_AP)** และ **AP+STA Mode (WIFI_AP_STA)**
2. สามารถใช้คำสั่ง `WiFi.scanNetworks()` เพื่อค้นหา SSID, ค่าความแรงสัญญาณ (RSSI), หมายเลขช่องสัญญาณ (Channel) และระบบความปลอดภัย (Security Type)
3. สามารถเชื่อมต่อเครือข่าย Wi-Fi ด้วยคำสั่ง `WiFi.begin(ssid, password)` และดึงหมายเลข IP Address, Subnet Mask, Gateway และ MAC Address
4. สามารถเขียนระบบกะพริบไฟ LED แจ้งสถานะการเชื่อมต่อ และการเชื่อมต่อเครือข่ายใหม่อัตโนมัติ (Auto-reconnect) เมื่อสัญญาณหลุด

---

## ✍️ เฉลยคำตอบในใบงาน (Worksheet Answers)

### 1. โค้ดหลัก (Key Commands)
* การสแกนหาเครือข่าย Wi-Fi:
  ```cpp
  WiFi.mode(WIFI_STA);
  WiFi.disconnect();
  int n = WiFi.scanNetworks();
  ```
* การเชื่อมต่อ Wi-Fi และตรวจสอบสถานะ:
  ```cpp
  WiFi.begin(TARGET_SSID, PASSWORD);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  ```

### 2. คำถามสรุปผลการทดลอง (Review Questions)

**คำถามที่ 1: ค่าความแรงสัญญาณ RSSI มีหน่วยเป็นอะไร และเหตุใดจึงแสดงผลเป็นค่าติดลบ?**
> **แนวคำตอบ:** RSSI (Received Signal Strength Indicator) มีหน่วยเป็น **dBm (เดซิเบลมิลลิวัตต์)** โดยอ้างอิงเทียบกับกำลังส่ง 1 มิลลิวัตต์ (0 dBm) เนื่องจากสัญญาณคลื่นวิทยุไร้สายที่เดินทางมาถึงภาครับมีกำลังต่ำมากในระดับไมโครวัตต์หรือนาโนวัตต์ จึงคำนวณตามสูตรลอการิทึมได้ค่าเป็นลบเสมอ เช่น `-40 dBm` คือสัญญาณแรงมาก และ `-85 dBm` คือสัญญาณอ่อนมาก

**คำถามที่ 2: โหมด Station (STA) และ Access Point (AP) แตกต่างกันอย่างไรในการประยุกต์ใช้งานระบบ IoT?**
> **แนวคำตอบ:** โหมด **Station (STA)** ทำให้อุปกรณ์ ESP ทำหน้าที่เป็น Client เพื่อเกาะเข้ากับ Wi-Fi Router หลักสำหรับการส่งข้อมูลขึ้น Cloud หรือเชื่อมต่อกับเซิร์ฟเวอร์ภายนอก ส่วนโหมด **Access Point (AP)** ทำให้อุปกรณ์ ESP ปล่อยสัญญาณ Wi-Fi ของตัวเองออกมาให้อุปกรณ์อื่น (เช่น มือถือ หรือคอมพิวเตอร์) เข้ามาเชื่อมต่อโดยตรง นิยมใช้ในการตั้งค่าฮาร์ดแวร์ครั้งแรก (Configuration Portal)
