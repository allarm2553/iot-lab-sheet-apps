🚀 ใบงานที่ 6 Perform: ระบบกำหนดค่าผ่าน WebConfig & ระบบสร้าง Topic ด้วย MAC Address

การแยกหน้า Dashboard (/index.html) ออกจากหน้า Config (/config.html) และการสร้าง Sub/Pub Topic อัตโนมัติตาม MAC Address

🌐 หน้าเว็บระบบควบคุม & กำหนดค่า (Live Web Pages)

คุณสามารถทดสอบเข้าชมหน้า Web Application ทั้ง 2 ส่วนที่แยกออกจากกันอย่างสมบูรณ์:

📊 เปิดหน้า Dashboard (/index.html) ⚙️ เปิดหน้า MCU Config Portal (/config.html)

🎯 1. วัตถุประสงค์และการทำงานของ LAB6_Perform

  • การแยกหน้า Config ออกจาก Dashboard: เพื่อความปลอดภัยและความสะดวกของผู้ใช้ทั่วไป ไม่ให้เห็นหรือแก้ไขค่า Network/Hardware พร่ำเพรื่อ
  • การบันทึกค่าลง LittleFS: จัดเก็บค่า `config.json` ลงใน Flash Memory ไม่สูญหายเมื่อปิดไฟ
  • การสร้าง Sub/Pub Topic อัตโนมัติ: ดึง Clean MAC Address เช่น `246F28ABCDEF` มาสร้าง Sub: `esp-node/246F28ABCDEF/control/cmd` และ Pub: `esp-node/246F28ABCDEF/state` ทำให้ทุกบอร์ดในห้องเรียนไม่เกิดปัญหา Topic ชนกัน
