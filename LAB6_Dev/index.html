🎯 วัตถุประสงค์การเรียนรู้ (Learning Objectives)
  • 1. เข้าใจสถาปัตยกรรม Hybrid Dual-Protocol: สามารถอธิบายหลักการทำงานคู่ขนานระหว่าง Local WebSockets (Port 81) และ Cloud MQTT Broker (`broker.emqx.io`:1883) ในโหนดเดียวกันได้
  • 2. พัฒนาโปรแกรมสื่อสารสองทางบน ESP32/ESP8266: สามารถเขียนโค้ด C++ (PlatformIO) จัดการ `WebSocketsServer` และ `PubSubClient` พร้อมจอ OLED SSD1306 แบบ Non-blocking
  • 3. ออกแบบระบบซิงโครไนซ์สถานะสองทิศทาง (State Synchronization): สามารถส่งและรับคำสั่ง JSON เพื่อกระจายสถานะ (Broadcast & Publish) ไปยังทุกช่องทางเมื่อสถานะอุปกรณ์เปลี่ยนแปลง
  • 4. พัฒนา Web Dashboard สลับโหมดการเชื่อมต่อ: สามารถใช้งาน Web Interface ที่เลือกสลับการเชื่อมต่อระหว่าง Local WS และ Cloud MQTT ได้ตามสภาพแวดล้อมเครือข่าย
  • 5. วิเคราะห์ความหน่วงและประยุกต์ใช้ระบบสำรอง (Redundancy & Fallback): สามารถเปรียบเทียบข้อดี-ข้อเสียด้าน Latency/Bandwidth และประยุกต์ใช้เป็นกลไกสำรองเมื่ออินเทอร์เน็ตขัดข้อง
