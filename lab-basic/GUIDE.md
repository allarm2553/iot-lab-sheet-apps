# 📘 ใบงานพื้นฐาน: การติดตั้ง Arduino IDE และคุณลักษณะของ ESP32 / ESP8266

คู่มือการเรียนรู้และทดลองเริ่มต้นสำหรับไมโครคอนโทรลเลอร์ **ESP32** (เช่น บอร์ด IPST-WiFi) และ **ESP8266** (เช่น บอร์ด AX-WiFi / NodeMCU)

---

## 🎯 วัตถุประสงค์ (Objectives)
1. เข้าใจสถาปัตยกรรมและคุณสมบัติฮาร์ดแวร์ของไมโครคอนโทรลเลอร์ ESP32 และ ESP8266 (ความเร็วสัญญาณนาฬิกา, ขนาดหน่วยความจำ, GPIO, Wi-Fi/Bluetooth)
2. สามารถติดตั้งและตั้งค่าโปรแกรม **Arduino IDE** หรือ **PlatformIO (VS Code)** สำหรับการเขียนโปรแกรมควบคุมบอร์ด
3. เข้าใจฟังก์ชันพื้นฐานของภาษา C/C++ สำหรับไมโครคอนโทรลเลอร์ (`setup()`, `loop()`, `pinMode()`, `digitalWrite()`, `delay()`)
4. เข้าใจข้อจำกัดของพิน GPIO ต่างๆ เช่น **Input-Only Pins** และ **Strapping Pins / Boot Configuration Pins**

---

## 🔌 การต่อวงจรและพินฮาร์ดแวร์ (Hardware Pinouts)

| ฟังก์ชัน | บอร์ด ESP32 (IPST-WiFi / ESP32 Dev) | บอร์ด ESP8266 (AX-WiFi / NodeMCU) | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| **LED On-board** | `GPIO 2` หรือ `GPIO 18` (IPST-WiFi) | `GPIO 2` (`D4`) หรือ `GPIO 16` (`D0`) | LED แสดงสถานะบนบอร์ด |
| **Push Button** | `GPIO 0` (SW1) | `GPIO 0` (`D3` - FLASH Button) | สวิตช์ปุ่มกด |
| **Input-Only Pins** | `GPIO 34, 35, 36 (VP), 39 (VN)` | `ADC0` (`A0` แอนะล็อกเท่านั้น) | ขาอินพุต ไม่มีวงจร Internal Pull-up/down |
| **Strapping Pins** | `GPIO 0, 2, 5, 12, 15` | `GPIO 0, 2, 15` | ขากำหนดโหมดการบูต (Boot Mode) ห้ามต่อดึงแรงดันค้างไว้ |

## ✍️ เฉลยคำตอบในใบงาน (Worksheet Answers)

### 1. โค้ดเติมช่องว่าง (Code Blanks)
การเขียนโปรแกรมไฟกะพริบ (Blink LED):
```cpp
void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(1000);
  digitalWrite(LED_PIN, LOW);
  delay(1000);
}
```

### 2. คำถามสรุปผลการทดลอง (Review Questions)

**คำถามที่ 1: ขา GPIO ใดของ ESP32 ที่ทำหน้าที่เป็น Input-Only (ไม่สามารถสั่ง Output ได้) และมีข้อควรระวังอย่างไร?**
> **แนวคำตอบ:** ขา `GPIO 34, 35, 36 (VP), 39 (VN)` เป็นพิน Input Only บน ESP32 โดยไม่มีวงจร Internal Pull-up / Pull-down ภายในตัวชิป จึงเหมาะสำหรับรับค่าเซ็นเซอร์แอนะล็อก (ADC) หรือดิจิทัลอินพุตที่มีตัวต้านทานภายนอกเท่านั้น และไม่สามารถสั่ง `OUTPUT` หรือต่อขับอุปกรณ์เอาต์พุตได้

**คำถามที่ 2: Strapping Pins บนบอร์ด ESP32/ESP8266 คืออะไร และมีผลกระทบอย่างไรต่อการอัพโหลดโค้ดหรือการบูตบอร์ด?**
> **แนวคำตอบ:** Strapping Pins (เช่น GPIO 0, 2, 15 บน ESP32 หรือ GPIO 0, 2, 15 บน ESP8266) คือขาที่ชิปใช้ตรวจสอบระดับแรงดันไฟฟ้า (Logic HIGH/LOW) ขณะเริ่มจ่ายไฟเพื่อเลือกโหมดการทำงาน เช่น โหมดรันโปรแกรมปกติ (SPI Flash Boot) หรือโหมดอัพโหลดโปรแกรม (UART Download Boot) หากมีการต่อโหลดภายนอกที่ดึงระดับแรงดันผิดพลาด อาจทำให้บอร์ดไม่ยอมบูตหรืออัพโหลดโค้ดไม่เข้า
