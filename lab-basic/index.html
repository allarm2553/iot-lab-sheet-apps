1. การดาวน์โหลดและติดตั้ง Arduino IDE

การเขียนโปรแกรมลงบอร์ด IPST-WiFi (ESP32) หรือ AX-WiFi (ESP8266) จำเป็นต้องมีสภาพแวดล้อมในการเขียนโปรแกรม (IDE) และไดรเวอร์ติดต่อสื่อสารกับคอมพิวเตอร์ ดังนี้:

  1. ดาวน์โหลดและติดตั้ง Arduino IDE 2.x จากหน้าเว็บทางการ arduino.cc
  2. ติดตั้งไดรเวอร์เชื่อมต่อ USB-to-UART ขึ้นอยู่กับชิปควบคุมบนบอร์ดของคุณ:
    • ชิป CP2102 / CP2104 / CH340: บอร์ด IPST-WiFi และ AX-WiFi มีชิปสื่อสารติดตั้งมาแล้ว ให้ติดตั้งไดรเวอร์ที่ตรงกันเพื่อให้ระบบสืบค้น COM Port พบ
  3. เปิดโปรแกรม Arduino IDE ไปที่เมนู File → Preferences
  4. ในช่อง Additional boards manager URLs ให้คัดลอก URL ของบอร์ดที่ใช้ไปวาง (หากมีหลาย URL ให้คั่นด้วยเครื่องหมายจุลภาค `,`):
    ESP32 Board Manager URL (สำหรับ IPST-WiFi)
    ESP8266 Board Manager URL (สำหรับ AX-WiFi)
  5. ไปที่เมนูเครื่องมือด้านซ้าย เลือก Boards Manager ค้นหาคำว่า esp32 (โดย Espressif Systems) หรือ esp8266 (โดย ESP8266 Community) แล้วกดปุ่ม Install

ทฤษฎีที่เกี่ยวข้อง: การติดตั้ง Arduino IDE และคุณลักษณะของ ESP32 / ESP8266

1.1 เปรียบเทียบคุณลักษณะ ESP32 และ ESP8266

ไมโครคอนโทรลเลอร์ทั้งสองรุ่นเป็นชิปยอดนิยมในงาน IoT โดยมีสเปกหลักที่แตกต่างกันดังนี้:

คุณสมบัติ ESP32 (IPST-WiFi / DevKit) ESP8266 (AX-WiFi / NodeMCU)
ซีพียู (CPU) Dual-Core Xtensa LX6 (240 MHz) Single-Core Tensilica L106 (80/160 MHz)
หน่วยความจำ RAM 520 KB SRAM ~80 KB User SRAM
การเชื่อมต่อไร้สาย Wi-Fi 802.11 b/g/n + Bluetooth 4.2 BLE Wi-Fi 802.11 b/g/n (ไม่มี Bluetooth)
ความละเอียด ADC 12-bit (0 – 4095) หลายช่อง 10-bit (0 – 1023) ช่องเดียว (A0)

2.1 ขา GPIO ชนิด Input-Only บน ESP32

บนบอร์ด ESP32 ขา GPIO 34, 35, 36 (VP), 39 (VN) เป็นขาอินพุตอย่างเดียวเท่านั้น:

  • ไม่มีวงจรตัวต้านทาน Pull-up / Pull-down ภายใน (ต้องต่อตัวต้านทานภายนอกเองหากใช้เป็นดิจิทัลสวิตช์)
  • ไม่สามารถสั่งเป็น OUTPUT ได้ ไม่สามารถขับ LED หรือรีเลย์ได้
  • นิยมใช้สำหรับรับค่าเซ็นเซอร์แอนะล็อก (ADC) หรืออินพุตภายนอกที่มีวงจรสมบูรณ์แล้ว

3.1 ขากำหนดโหมดการบูต (Boot Configuration Pins)

Strapping Pins คือขาที่ชิปใช้ตรวจจับระดับแรงดัน (HIGH/LOW) ขณะเริ่มจ่ายไฟ (Power-on Reset) เพื่อเลือกโหมดการทำงาน:

  • GPIO 0: หากขณะบูตเป็น LOW จะเข้าสู่โหมด UART Download Mode (รอรับโค้ด), หากเป็น HIGH จะเข้าสู่โหมด Flash Boot (รันโปรแกรมปกติ)
  • GPIO 2, GPIO 12, GPIO 15: ควบคุมระดับแรงดันไฟเลี้ยง Flash และการส่งสัญญาณ Debug ออก Serial
  • ข้อควรระวัง: หลีกเลี่ยงการต่อวงจรภายนอกที่ดึงระดับแรงดันขาเหล่านี้ค้างไว้ เพราะอาจทำให้บอร์ดเปิดไม่ติดหรือไม่ยอมบูต
