# กฎ: ห้าม Push ขึ้น GitHub โดยอัตโนมัติ

## บังคับใช้กับโปรเจกต์นี้เสมอ

**ห้าม** รันคำสั่ง `git push` ทุกรูปแบบโดยที่ผู้ใช้ไม่ได้ขอให้ push อย่างชัดเจนในข้อความล่าสุด

## พฤติกรรมที่ถูกต้อง

1. **Commit ได้** — `git add` และ `git commit` สามารถรันได้ตามปกติหลังแก้โค้ด
2. **Push ต้องได้รับคำสั่งก่อน** — รัน `git push` ได้เมื่อผู้ใช้พูดอย่างใดอย่างหนึ่งต่อไปนี้:
   - "update to github"
   - "push"
   - "อัพโหลดขึ้น github"
   - "push ขึ้น github"
   - หรือคำสั่งที่มีความหมายเดียวกันอย่างชัดเจน
3. **หลัง commit** — ให้แจ้งผู้ใช้ว่า commit แล้ว และถามว่า "ต้องการ push ขึ้น GitHub ด้วยไหม?" แทนการ push ทันที

## ตัวอย่างพฤติกรรมที่ถูกต้อง

```
✅ รัน: git add . && git commit -m "fix: ..."
✅ แจ้ง: "commit เรียบร้อยแล้ว ต้องการ push ขึ้น GitHub ด้วยไหม?"
❌ ห้ามรัน: git push origin main   ← ถ้าผู้ใช้ยังไม่ขอ
```

## เหตุผล

ป้องกันการ push code ที่ยังไม่พร้อมหรือยังไม่ได้รับการตรวจสอบขึ้นไปยัง remote repository โดยไม่ตั้งใจ
