Package ZIP

ดาวน์โหลดชุดไฟล์ Web Dashboard

ชุดไฟล์ HTML/CSS/JavaScript พร้อมไอคอนที่บีบอัดเป็น .zip พร้อมสำหรับการนำไปแปลงบน WebIntoApp ทันที

ดาวน์โหลด iot_dashboard_package.zip
Cloud Builder

สร้างไฟล์ APK บน WebIntoApp

เปิดแพลตฟอร์ม Cloud Builder เพื่ออัปโหลดไฟล์ ZIP หรือระบุ URL แปลงเป็นไฟล์ติดตั้ง .apk ภายใน 2 นาที

ไปที่ WebIntoApp.com
Interactive PWA

ทดสอบ Mobile Controller App

เปิดใช้งาน Progressive Web App (PWA) เวอร์ชันทดสอบบนบราวเซอร์ พร้อม Service Worker และ Offline MQTT

เปิดทดสอบ Controller App

ขั้นตอนการแปลงเป็นแอปพลิเคชันมือถือ (.apk)

1

เตรียมไฟล์หรือดาวน์โหลด ZIP

กดปุ่ม "ดาวน์โหลด iot_dashboard_package.zip" ด้านบน หรือรันสคริปต์ package-dashboard-zip.ps1 เพื่อสร้างไฟล์แพ็กเกจแดชบอร์ดล่าสุด

powershell -ExecutionPolicy Bypass -File package-dashboard-zip.ps1
2

อัปโหลดขึ้น WebIntoApp.com

เปิดเว็บไซต์ WebIntoApp.com เลือกแท็บ "All Files in a Zip Archive" แล้วเลือกไฟล์ iot_dashboard_package.zip

3

ตั้งชื่อและกำหนดไอคอนแอป

กำหนดชื่อแอป เช่น IoT Controller, ระบุ App ID (เช่น com.iotlab.controller) และเลือกไอคอน 512x512 PNG

4

ดาวน์โหลดและติดตั้ง APK

เมื่อระบบ Build เสร็จสมบูรณ์ ดาวน์โหลดไฟล์ .apk ไปติดตั้งบนสมาร์ทโฟน Android และเปิดใช้งานได้ทันที
